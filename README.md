# Published Conference Paper: Differential Privacy

## Overview

This repository contains my published conference paper on a differentially private KPI-based framework for privacy–utility optimization in sensitive healthcare datasets.

## Research Focus

The work explores how differential privacy can protect individual-level information while preserving the analytical usefulness of key performance indicators (KPIs).

## Key Contributions

- Investigates privacy protection through controlled noise addition.
- Examines the trade-off between individual-level privacy and KPI accuracy.
- Studies the impact of privacy-budget settings on statistical utility.
- Evaluates privacy–utility balance across different privacy levels.
